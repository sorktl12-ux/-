# iPhone 단축어: 카카오톡 파일 → 다운로드 폴더 이동

Mac으로는 **iPhone '내 iPhone' 저장소**에 직접 접근할 수 없습니다.
아래 단축어를 iPhone에 한 번 설치하면, 카카오톡 폴더 파일을 다운로드 폴더로 옮깁니다.

## 설치 방법

1. iPhone **단축어** 앱 열기
2. 오른쪽 위 **+** → **새로운 단축어**
3. 이름: `카카오톡 파일 정리`
4. 아래 동작을 순서대로 추가

## 단축어 동작 (복사해서 구성)

### 동작 1: 폴더 내용 가져오기
- **파일** 카테고리 → **폴더 내용 가져오기**
- 폴더: `내 iPhone` → `KakaoTalk` (없으면 `kakao`)
- 하위 폴더 포함: **끔**

### 동작 2: 각 항목 반복
- **제어 흐름** → **각 항목 반복**

### 동작 3: (반복 안) 파일 이동
- **파일** → **파일 이동**
- 대상: `iCloud Drive` → `Downloads`
- 덮어쓰기: **끔** (원본 이름 유지)

### 동작 4: (반복 밖) 알림
- **알림 표시**: `카카오톡 파일 정리 완료`

## 홈 화면에 추가

단축어 상세 → **공유** → **홈 화면에 추가**

## 자동 실행 (선택)

단축어 상세 → **자동화** → **개인 자동화 만들기**
- **시간**: 매일 원하는 시간
- **동작**: `카카오톡 파일 정리` 실행

> iOS는 카카오톡 앱 내부 파일에 직접 접근하지 못합니다.
> **파일 앱에 저장된** KakaoTalk 폴더만 정리됩니다.

## 원본 파일명 유지 팁

단축어의 **파일 이동** 동작에서:
- **이름 바꾸기** 동작을 넣지 마세요
- 덮어쓰기가 켜져 있으면 끄세요

앞으로 받는 파일은 카카오톡에서:
**공유 → 파일에 저장 → 다운로드** (이름 확인 후 저장)
