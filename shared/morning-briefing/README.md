# 아침 브리핑 (메일 서비스)

GitHub 레포가 아니라 **Gmail 자가수신 + 카카오톡 「나와의 채팅」** 으로 동작한다.

## 포맷 (관측 2026-08)

- 제목: `[아침 운세] M/D (요일) 총운 N · {아침 메뉴}`
- 본문: 사주/일진 요약, 총운·애정·금전·직장·건강·대인 점수, 키워드, 식단, 코디, 행운색/숫자/아이템/방향
- 오늘 일정 (없으면 “등록된 일정이 없습니다”)
- 위치 반경 5km / 서울 전체 최저가 주유소 (고급유)

## 이 허브에서의 역할

- 최신 브리핑 요약을 `shared/MEMORY.md`에 남기면 다른 에이전트(캘린더·아이폰·beatlink)가 같은 날 맥락을 공유한다.
- 소스 코드 레포 URL이 생기면 `linked/registry.json`의 `morning-briefing.github`에 넣고 `./shared/bin/link-repos.sh` 실행.
